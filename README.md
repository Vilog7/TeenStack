# TeenStack — Student Networking & Learning Platform

A dark-futuristic, spring-morphing student networking, portfolio, and learning ecosystem built with **React 19**, **TypeScript**, **Tailwind CSS v4**, **Motion for React (`motion/react`)**, and **Express + Node 24 native SQLite (`node:sqlite`)**.

## Quick Start

```bash
npm install
npm run dev
```

- **Frontend (Vite):** `http://localhost:5173`
- **Backend API & SQLite (`server/index.mjs`):** `http://127.0.0.1:3001`
- **Demo Student Account:** `arav@teenstack.edu` / `TeenStack@2026`
